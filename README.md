# Pulse Tapestry: Layout Viewer

Interactive 3D viewer of the Pulse Tapestry light installation by Rafael Lozano-Hemmer / Antimodular.

**View it here:** https://antiemily.github.io/pulse-tapestry-viewer/

It shows the position, cable length and label of each of the 980 bulbs, hanging from the dimmer enclosures. The layout is subject to change.

## How to use

- Drag to rotate, scroll to zoom, right-drag to pan
- Hover a bulb to see its details, click it to highlight its line
- Use the view buttons (3D, Front, Side, Plan) to change angle
- "Measure between two bulbs" gives the distance between any two points
